# HomeTask

## Интеллектуальная веб-платформа управления бытовыми задачами с контекстными советами и аналитикой привычек

**HomeTask** — проект, представляющий собой full-stack веб-платформу для планирования, распределения, контроля выполнения и анализа бытовых задач в условиях индивидуального и совместного использования. Система ориентирована на снижение когнитивной нагрузки пользователей, повышение прозрачности распределения домашних обязанностей и формирование устойчивых полезных привычек. 


**«Разработка интеллектуальной веб-платформы управления бытовыми задачами с контекстными советами и аналитикой привычек»**. 

---

## 1. Назначение проекта

Актуальность разработки обусловлена тем, что существующие способы организации бытовых задач, как правило, не обеспечивают одновременно:
- удобное планирование регулярных и нерегулярных задач;
- прозрачное распределение ответственности между участниками;
- накопление истории выполнения;
- аналитику привычек;
- контекстную информационную поддержку пользователя. 

Проектируемая система предназначена для решения следующих задач:
- централизованное управление бытовыми задачами;
- поддержка совместного быта в рамках дома;
- фиксация истории действий по задачам;
- расчет метрик дисциплины и регулярности выполнения;
- предоставление контекстных советов на основе базы знаний;
- создание основы для последующего развития платформы в полноценное PWA-решение. 
---

## 2. Цель разработки

Цель проекта — разработать интеллектуальную веб-платформу управления бытовыми задачами для совместного и индивидуального использования, обеспечивающую планирование и контроль выполнения домашних дел, предоставление контекстных советов на основе базы знаний и аналитику привычек выполнения. 

---

## 3. Основные возможности системы

На текущем этапе реализации проект включает следующие функциональные возможности:

### 3.1. Управление задачами
- создание, редактирование и гибкое удаление задач;
- поддержка различных типов повторяемости:
  - разовая задача;
  - ежедневная;
  - еженедельная;
  - ежемесячная;
  - пользовательский интервал;
- назначение ответственного участника;
- привязка задачи к помещению;
- указание политики обработки пропусков (`move`, `overdue`, `skip`). 

### 3.2. Управление событиями выполнения
- фиксация статусов выполнения задач;
- хранение даты экземпляра задачи;
- поддержка статусов:
  - `done`,
  - `skipped`,
  - `overdue`,
  - `moved`;
- предотвращение дублирования событий выполнения для одного экземпляра задачи. 

### 3.3. Совместное использование
- работа в контексте дома (`house`);
- учет участников дома с ролями:
  - `admin`,
  - `member`,
  - `limited`;
- управление помещениями и участниками. 

### 3.4. Аналитика привычек
- расчет ключевых метрик выполнения:
  - `adherence_rate`,
  - `streak`,
  - `completion_ratio`,
  - `overdue_rate`,
  - `daily_trend`,
  - `load_distribution`;
- визуализация аналитических данных на клиентской части. 

### 3.5. База знаний и советы
- хранение советов по бытовым задачам;
- отображение советов по комнатам;
- формирование основы для интеллектуального подбора рекомендаций под пользовательский контекст. 

---

## 4. Архитектура решения

Проект реализован как клиент-серверное приложение с разделением на backend и frontend.

### 4.1. Серверная часть
Серверная часть реализована на **Python 3.12** с использованием:
- **FastAPI**
- **SQLAlchemy (async)**
- **Alembic**
- **PostgreSQL**
- **Pydantic v2**
- **JWT-аутентификации**. 

Сервер отвечает за:
- аутентификацию и авторизацию пользователей;
- доступ к данным;
- бизнес-логику задач и событий;
- расчет аналитических показателей;
- предоставление API для клиентской части. 

### 4.2. Клиентская часть
Клиентская часть реализована на:
- **React 18**
- **TypeScript**
- **Vite**
- **Tailwind CSS**
- **React Router**
- **TanStack React Query**
- **Zustand**
- **Recharts**.

Интерфейс включает страницы:
- авторизации;
- панели управления;
- задач;
- аналитики;
- дома;
- базы знаний. 

### 4.3. Инфраструктура
Для локального и демонстрационного развертывания используется:
- **Docker Compose**
- **PostgreSQL 16**
- контейнеризация backend и frontend.
